A modern, high-performance personal software engineering portfolio built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite**. Features an iridescent **Living Wallpaper** with 43 realistic 3D floating water bubbles, frosted glassmorphism UI, executive circular portrait framing, and direct email delivery via **Web3Forms**.

🔗 **Live Website**: [https://ravindu-portfolio-psi.vercel.app](https://ravindu-portfolio-psi.vercel.app)

---

## 🚀 Key Features

- **Living Wallpaper & Aurora Dynamics**: Ambient glowing mesh with 43 realistic 3D translucent water bubbles rising with organic sway and negative initial delays.
- **Executive Circular Portrait Avatar**: Frosted glass border, multi-tier cyan-indigo gradient glow rings, with responsive mobile framing.
- **Interactive Projects Showcase**: Categorized filter tabs (All, Full-Stack & Web, Enterprise & Desktop, Mobile) featuring flagship architecture highlights and direct GitHub links.
- **Technical Skills Matrix**: Curated skill domains spanning Languages & Backend, Frontend & Mobile, Databases, ML & Enterprise IT Operations.
- **Direct Contact Form**: Seamless API integration powered by **Web3Forms** delivering visitor messages straight to email inbox without opening third-party mail clients.
- **Executive Confirmation Toast**: Floating glassmorphic notification with 3D gradient status badge, "Direct to Inbox" verified pulse, and 5-second countdown progress bar.
- **One-Click Smooth Scroll to Top**: Context-aware floating glass action button that appears on scroll and smoothly glides to the top.
- **Curriculum Vitae Download**: Instant one-click PDF CV download integrated across the Hero section, Header, Mobile Drawer, and About Me section.
- **100% Mobile Responsive**: Tailored layout for all screen sizes (iPhone SE, modern smartphones, tablets, laptops, and ultra-wide desktop monitors).

## 💻 Local Development

### 1. Prerequisites
Ensure you have **Node.js** (v18 or higher) installed.

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/ravindu-n/ravindu-portfolio.git
cd ravindu-portfolio
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for Production
```bash
npm run build
```
Generates optimized, minified production assets in the `dist/` directory.
